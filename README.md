## Goals

1. Students can use this system to report their lost items.
2. Students can use this system to report items that they find.
3. Students can use this system to search for lost or found items.
4. Students can use this system to make claims on items that are believed to be theirs.
5. This system will serve as a learning tool for students to learn Python programming concepts and how to develop modular programs.

## Modules

### 1. Report Lost Item
This module provides the ability for users to input information regarding an item they have lost. Examples of the types of information a user may provide include:
* User Name
* Item Name
* Item Location
* Item Date
* Item Description

### 2. Report Found Item
This module provides the ability for users to provide information about an item they have located. Examples of the types of information a user may provide include:
* User Name
* Item Name
* Item Location
* Item Date
* Item Description

### 3. Search Item
This module provides the ability for users to enter the name of an item that they wish to search for. Once the user enters the name of the item, the system will look through all of the lost and found item records to see if there is a match.

### 4. Claim Item
This module provides the ability for users to search for an item that they believe belongs to them and submit a claim for that item.
